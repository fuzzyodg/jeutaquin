## 2025-05-15 - [Accessible Cart & Navigation Polish]
**Learning:** Transitioning legacy vanilla JS components (like the shopping cart) to semantic HTML requires careful synchronization between the DOM structure and event delegation. Specifically, using `aria-live="polite"` on numerical values and semantic `<button>` elements with `aria-label` provides immediate accessibility wins without disrupting the visual design. Furthermore, implementing the 'Escape' key for modal dismissal is a critical but often overlooked micro-UX pattern in custom-built panels.
**Action:** Always prioritize semantic `<button>` tags over generic `<div>` or `<span>` for interactive elements, and ensure all dynamic state changes are wrapped in ARIA live regions for screen reader compatibility. Avoid `target="_blank"` for internal navigation to maintain session state and user flow.
