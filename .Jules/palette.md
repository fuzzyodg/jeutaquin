## 2025-06-19 - Shopping Cart Micro-UX & Accessibility
**Learning:** Enhancing a vanilla JS shopping cart with semantic <button> elements, descriptive ARIA labels, and aria-live="polite" significantly improves the experience for assistive technology users. Using event delegation instead of inline onclick handlers improves code maintainability and security.
**Action:** Always prioritize semantic elements over generic spans for interactive controls and use ARIA live regions for dynamic numerical updates.
