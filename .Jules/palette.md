## 2026-06-11 - Enhanced Cart Accessibility & Micro-interactions
**Learning:** In a vanilla JS environment, using event delegation for dynamic elements (like cart items) significantly simplifies event management and prevents memory leaks from repeated listener attachments. Adding visual feedback (bump animation) combined with accessibility cues (aria-live) creates a cohesive "tradi-modern" feel that is both delightful and inclusive.
**Action:** Always favor event delegation for dynamic lists and pair visual animations with semantic ARIA updates to ensure the UI state is clear to all users.
