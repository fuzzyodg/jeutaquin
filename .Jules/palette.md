## 2025-05-20 - Accessible Cart Item Controls & Dynamic Toast Notifications
**Learning:** In vanilla JS applications rendering dynamic lists into innerHTML (like shopping cart panels), using non-semantic elements (`<span>` with `onclick`) prevents keyboard focusability and screen reader accessibility. Refactoring to semantic `<button type="button">` with descriptive `aria-label`s and event delegation via `data-action` / `data-name` attributes ensures full accessibility without inline JavaScript. Additionally, dynamic toast notifications created via JS must include `role="status"` and `aria-live="polite"` so screen readers announce feedback upon user actions.
**Action:** Always render semantic interactive elements with explicit ARIA labels and event delegation for dynamic templates, and ensure live region attributes are set when creating toast notification containers.
