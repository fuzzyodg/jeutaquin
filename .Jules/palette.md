# Palette Journal - A'kadi Restaurant

## 2025-05-22 - Shopping Cart UX & Accessibility Standardization
**Learning:** In a vanilla JS multi-page application, centralized event delegation for dynamic elements (like cart items) improves performance and maintainability. Using semantic elements and ARIA attributes for live regions ensures a "luxury" experience remains inclusive.
**Action:** Replace inline event handlers with delegation on `#cart-body`, use `<button>` for actions, and apply `aria-live="polite"` for numerical updates.
