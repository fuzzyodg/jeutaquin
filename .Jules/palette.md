## 2025-05-22 - [Shopping Cart Accessibility & Navigation Consistency]
**Learning:** In vanilla multi-page projects without templating engines, mobile navigation links frequently diverge from desktop links, leading to broken internal paths (e.g., `accueil.html` vs `index.html`). Additionally, dynamic UI elements like shopping carts are often implemented with non-semantic elements and inline handlers, which breaks accessibility.
**Action:** Always use event delegation on a stable parent for dynamic components to keep HTML templates clean and semantic (`<button>` instead of `<span>`). Use a centralized sanitization helper (like `escAttr`) for all data-driven attributes to prevent injection while maintaining readability. Synchronize all internal navigation links across all HTML files to point to the canonical `index.html` and `evenement.html`.
