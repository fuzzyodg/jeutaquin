## 2026-06-05 - Navigation and Cart Accessibility Standardization
**Learning:** Inconsistent internal page naming (accueil.html vs index.html) and non-standard JS event handlers (onclick) were present despite strict agent directives. Semantic HTML and event delegation on dynamically rendered content are essential for accessibility and maintainability in this vanilla JS architecture.
**Action:** Always verify internal routing against the actual file list and use event delegation for all dynamically generated UI components.
