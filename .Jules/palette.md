## 2026-10-25 - Shopping Cart Accessibility & Dynamic Templates
**Learning:** Icon-only buttons (such as cart close, item remove, quantity adjustments) in dynamically rendered cart components must be semantic `<button>` elements equipped with descriptive `aria-label`s. Dynamically injected attributes must use HTML attribute escaping (`escAttr()`) to avoid broken HTML syntax. Additionally, toast notifications generated via JavaScript require `role="status"` and `aria-live="polite"` to ensure screen readers announce updates dynamically without stealing focus.
**Action:** When updating dynamic HTML template literals in vanilla JS apps, replace non-semantic clickables (`<span>`) with `<button>`, sanitize attributes with `escAttr()`, and initialize toasts with ARIA live region attributes.
