## 2026-07-19 - Standardizing Navigation Consistency and Link Security in Multi-Page Websites
**Learning:** In vanilla multi-page websites, navigation links are often duplicated across multiple static files, leading to drifts such as incorrect names (e.g. `accueil.html` instead of `index.html`), incorrect link behaviors (e.g. using `target="_blank"` on internal pages), and security/performance vulnerabilities (e.g. missing `rel="noopener noreferrer"` on external links). Standardizing these components is vital for a seamless UX and safe browsing.
**Action:** Always scan all static pages when modifying shared headers, footers, or navigation structures. Ensure internal links do not open in new tabs, and always append `rel="noopener noreferrer"` to external links using `target="_blank"`.
