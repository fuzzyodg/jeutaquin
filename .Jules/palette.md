## 2026-05-20 - Multi-Overlay Dismissal Pattern and Focus-Visible Navigation
**Learning:** In multi-page vanilla JS applications with multiple overlay components (drawer cart panels, mobile navigation drawers, and event modals), keyboard users can become trapped when focus remains inside an overlay or when no key listener exists for standard `Escape` dismissal. Adding a centralized `keydown` listener checking open overlay classes ensures predictable dismissibility without tightly coupling individual component lifecycles. Furthermore, defining `:focus-visible` with `outline-offset` in `common.css` preserves keyboard navigation clarity across all pages without triggering focus rings during pointer interactions.
**Action:** Always verify keyboard dismissal for all overlay/drawer/modal patterns and ensure explicit `:focus-visible` styles are declared on all interactive elements in `common.css`.
